##  Setup & Installation

1. **Clone the repository:**

   ```bash
   git clone https://github.com/pmhunts/portfolio.git
   cd portfolio
   ```

2. **Open in browser:**

   - Simply open `portfolio.html` in your web browser
   - No server required - it's a static website

3. **Optional - Run locally with a server:**

   ```bash
   # Using Python (if installed)
   python -m http.server 8000

   # Or using Node.js
   npx serve .

   # Then visit http://localhost:8000/portfolio.html
   ```
